# Project Language

This project is English-only. These instructions apply to every file in `maat-gateway` and its subdirectories.

- Write all source file headers, comments, documentation, configuration descriptions, logs, and error messages in English.
- Write all interface text, labels, accessibility text, and demo content in English.
- Do not commit personal names, personal machine names, private host aliases, old domains, client secrets, or real `.env` files.
- Keep deployment host and domain values in the ignored `.env` file. `.env.example` may contain empty placeholders or the intended public demo domain.
- Use project-relative paths and generic deployment identifiers in tracked files. Do not add machine-specific absolute paths except for the generic production app directory required by the deployment configuration.
